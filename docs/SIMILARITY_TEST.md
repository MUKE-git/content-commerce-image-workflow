# 临时两图相似度测试系统

## 运行

```powershell
python -m pip install -r requirements-similarity.txt
python -m similarity_test.compare "原图.png" "待测图.png" --output "测试报告"
```

工具生成 `report.json` 和 `report.md`。损坏、缺失或超过 3000 万像素的图片会报错，不会产生判定。两图可以是 JPG、PNG、WebP、BMP、TIFF 等 Pillow 可读格式。

## 口径

本系统参照附件项目的 MSE、PSNR、SSIM、MAD 四项指标及其 50%、30%、10%、10% 权重。综合分数达到 75 判“重复”，达到 60 而不足 75 判“疑似重复”，低于 60 判“不重复”。完全相同图片的 PSNR 数学值为无穷，JSON 用 `null` 表示，报告显示为 `∞`。

在计算前，系统校正 EXIF 方向，等比例缩放并置于相同的 512×512 白底画布。相较附件代码的直接拉伸，这样能保留宽高比；不同裁剪、边框和局部移动仍可能明显影响分数。SSIM 固定采用 8 位图片的 255 动态范围。因此本工具复用附件的评分规则，但数值不保证与其原环境逐位相同。报告保留图片尺寸、对齐方式、权重和阈值，便于复核。

## 与社交平台去重的关系

测试时，一张图为从社媒下载的已发布内容，另一张为待测图片。这样构成了明确的“已有内容参照图—待测图”对照，与图片重复内容核查的目标一致，无需把历史内容库检索作为本次测试条件。

本系统的可比性主要体现在：对同一对图片使用固定的方向校正、等比例对齐、四项图像指标、权重和判定阈值；每次报告保留输入尺寸、指标和评分规则，可以复算和复核。它对完全相同、轻微改动和明显不同的图片给出连续分数，适合比较一组处理前后图片的相对变化。后续应以实际样本验证这些场景下的排序与判定是否符合人工观察。

相似分和“重复／疑似重复／不重复”是本系统的离线测试结果。社交平台可能使用其他图像特征及内容、账号信号，内部规则未知；因此这些结果可作为图片相似程度的参考数据，但不等同于小红书、抖音等平台的实际审核结果，也不能用百分比表示本系统对平台判定的准确率。
